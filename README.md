## Projeto em destaque

### Sistema de Pet Shop — Java

Sistema acadêmico desenvolvido para simular operações comerciais de um pet shop.

**Principais funcionalidades:**
- Registro de vendas e cálculo de descontos
- Gerenciamento de produtos e estoque
- Cálculo de lucro e margem de lucro
- Relatórios de faturamento e vendas
- Validação de entradas e tratamento de exceções

**Conceitos utilizados:** Java, orientação a objetos, encapsulamento e organização em classes.
